# 3DFabrica Features

## Authentication & Security
- **Supabase PKCE Auth**: Secure authentication flow using Proof Key for Code Exchange.
- **Google OAuth Integration**: Seamless sign-in with Google accounts.
- **Protected Routes**: Secure access to the Fabric Studio and user dashboards.
- **Session Persistence**: Long-lived sessions with automatic token refresh.

## Fabric Studio
- **3D Real-time Rendering**: Interactive 3D preview of fabrics on furniture models.
- **High-Resolution Mapping**: Support for high-quality texture mapping (512x512+).
- **Material Controls**:
  - **Tiling Scale**: Adjust pattern repetition.
  - **Rotation**: Rotate fabric patterns in real-time.
  - **Roughness**: Fine-tune surface reflectivity based on fabric type (Silk, Velvet, Cotton, etc.).
- **Auto-Collapsing Sidebar**: Intelligent sidebar that expands on hover (30px trigger zone) to maximize workspace.

## Fabric Management
- **Smart Filtering**: Focused catalog showing only Upholstery and Curtain fabrics.
- **Custom Uploads**: Instant upload and mapping of user-provided fabric images.
- **Technical Sheet Export**: Professional PDF generation with 3D parameters and texture samples.

## Design & UX
- **Minimalist Aesthetic**: Clean white/slate interface to keep focus on fabric textures.
- **Responsive Design**: Fully functional across desktop and mobile browsers.
- **SPA Routing**: Smooth transitions with Vercel-optimized routing.
